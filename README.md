# digital-local-plan-prototypes

Coded prototypes for the Digital Local Plan project - https://www.digitallocalplan.info/. These
prototypes are in part generated by AI coding agents.

Built with the [GOV.UK Prototype Kit](https://prototype-kit.service.gov.uk/), using
[GOV.UK Frontend](https://design-system.service.gov.uk/) components and styles.

## Running the prototype

```
npm install
npm run dev
```

Then visit http://localhost:3000.

## Prototypes

The landing page (`app/views/index.html`) links to each prototype, currently:

- **Project management** — how planners can manage a local plan-making process.
- **Evidence** — how planners can identify, gather, analyse and use evidence in the plan-making
  process.
- **Policy writing** — how planners can write policy that is connected to evidence, consultation
  inputs and tracked over time.
