# CLAUDE.md

Guidance for Claude Code (and other AI coding agents) working in this repository.

## Project

`digital-local-plan-prototypes` — coded prototypes for the Digital Local Plan project
(https://www.digitallocalplan.info/), for Local Planning Authorities (LPAs) in England.
Prototypes here are in part generated by AI coding agents.

## Stack

- [GOV.UK Prototype Kit](https://prototype-kit.service.gov.uk/) (Node.js + Express + Nunjucks).
- [GOV.UK Frontend](https://design-system.service.gov.uk/) components, via the kit's built-in
  Nunjucks macros and layouts.
- Styling is Sass compiled to CSS by the kit — edit `app/assets/sass/application.scss`, don't
  hand-write compiled CSS.

## Commands

```
npm install     # install dependencies
npm run dev     # run the prototype locally with hot reload, at http://localhost:3000
```

## Structure

- `app/views/index.html` — the landing page. Lists every prototype with a short description and
  the user need it addresses.
- `app/views/<slug>/index.html` — one folder per prototype (e.g. `project-management`,
  `evidence`, `policy-writing`). The kit auto-routes any `app/views/<path>/index.html` to
  `/<path>` — no entry in `app/routes.js` is needed unless a page requires custom server logic
  (form handling, session data, etc.).
- `app/routes.js` — custom Express routes, only when file-based routing isn't enough.
- `app/assets/sass/application.scss` — project-specific Sass, imported alongside GOV.UK
  Frontend's styles.
- `app/config.json` — service name and kit-level config.

## Adding a new prototype

1. Create `app/views/<slug>/index.html`, extending `layouts/main.html` (see existing prototypes
   for the pattern: heading, intro paragraph, "User need" statement, back link to `/`).
2. Add an entry to `app/views/index.html` linking to it, with a short description and a
   "User need:" line, matching the existing entries' format.

## Keeping this file current

As conventions evolve (new shared layouts, session data patterns, testing setup, etc.), update
this file to reflect them. Keep it accurate rather than aspirational.
