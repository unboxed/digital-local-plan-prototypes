Project management

Prototypes exploring how planners can manage a local plan-making process: setting the timetable, agreeing how the work will be run, and keeping track of what is due next. Pick one to try it out.

User need: As a planner, I need to manage a local plan-making process.

Current prototypes

These are the most recent prototypes we've developed. We'll be testing these over the next few weeks.

Make your plan

Start plan-making: create and publish the Local Plan timetable, schedule its milestones for committee, write and approve the Project Initiation Documentation, and publish the notice of intention to commence.

Publish plan versions

An initial concept for publishing or sharing versions of your local plan. This prototype covers the option to:

  • publish the whole plan, images and associated layers and capture version details
  • view versions side by side
  • share chapters or a draft plan internally for non-public review

We're interested in learning about where this type of 'sharing' might happen within the drafting workflow.

It also includes an examination library, the public view of the submitted plan and its examination documents, designed so readers can be sure which version they're looking at.
