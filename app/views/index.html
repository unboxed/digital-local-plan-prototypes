Coded prototypes exploring how Local Planning Authorities (LPAs) in England could create Digital Local Plans. Each prototype below explores a different part of the plan-making process — pick one to try it out.

Project management

How planners can manage a local plan-making process.

User need: As a planner, I need to manage a local plan-making process.

Evidence

How planners can identify, gather, analyse and use evidence in the plan-making process.

User stories

E1US1 As a policy officer I need to procure evidence in a standard format so that I can spend less time analysing it

E1US2 As a policy officer I need to know if we already have or are procuring evidence I need so that I can avoid duplicating effort

E1US3 As a policy officer I need to see all the needs for evidence across the team so that I can effectively procure responses

E1US4 As a policy officer I need to directly view and use the latest most relevant sections of the NPPF

E1US5 As a policy officer I need to store all my evidence in one place so I can access, export and track it

Policy writing

How planners can write policy that is connected to evidence, consultation inputs and tracked over time.

User need: As a planner, I need to write policy that is connected to evidence, consultation inputs and tracked over time.

Policy writer v2

A second take on the drafting workspace, on a wider screen: evidence and the policy draft side by side, with a divider you can drag to give more room to whichever you need.

User need: As a policy officer, I need to draft a policy while reading the evidence behind it, so I can check my wording against my sources as I write.
